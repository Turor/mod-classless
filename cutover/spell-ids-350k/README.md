## Files
- `world.sql`: world DB, both realms (spell_target_position + guards for other spell tables). Idempotent.
- `characters.sql`: characters DB, both realms (character_action/aura/talent/spell/cooldowns, pet tables). Idempotent. Run with worldserver stopped.
- `roguelike-parity-world.sql`: Roguelike world DB only: adds 200100 and 350001-350010 so both realms have the same custom spell_dbc rows.
- `renumber_dbc.py`: rewrites Spell.dbc (ID), SkillLineAbility.dbc (spell), Talent.dbc (spell_rank_0-8). Same DBCs go in patch-n and on both servers.
- Flyway: `apps/patchgenerator/dmls/migrations/V024__RenumberCustomSpells350k.sql`; `dmls/required/{Talent,SkillLineAbility}.sql` already regenerated by hand.
- Lua: `apps/classless-ui/CatalogData.lua` (ClasslessUI, both realms); `mod-turoran-roguelike` `lua_scripts/Gauntlet/GauntletData_Talents.lua` (Roguelike).

## Cutover (one window, both realms)
1. `/usr/local/sbin/wow-daily-restart.sh trigger` on .100 and .101 (5-minute in-game countdown), then at ~4:30 `systemctl stop` the worldserver unit (keeps it down; SIGTERM = graceful save).
2. Back up: `data/dbc/{Spell,Talent,SkillLineAbility}.dbc` -> `.bak-YYYYMMDD-HHMM`; affected DB rows; `CatalogData.lua` / `GauntletData_Talents.lua` `.bak`.
3. Apply `world.sql` + `characters.sql` on both realms; `roguelike-parity-world.sql` on Roguelike.
4. Copy the 3 renumbered DBCs into `data/dbc/` on both realms; deploy the two Lua files.
5. Publish the matching `patch-n.mpq` + signed manifest (classless-wow-patch skill `publish-patch-n.sh`).
6. `systemctl start` both; verify World Initialized, 50/50 bots, no rows left in 360001-360016, Talent UI shows the 11 custom talents, trainer teleports work.
